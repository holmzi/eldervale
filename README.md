# Eldervale

В этом репозитории публикуются официальные релизы сборки **Eldervale** в формате `.mrpack`.

Актуальная версия, предыдущие выпуски и списки изменений доступны в разделе [Releases](https://github.com/holmzi/eldervale/releases).

Репозиторий также служит источником обновлений для встроенного апдейтера, который автоматически проверяет наличие новых версий.

## Установка

Сборка работает на Windows и Linux, использует Minecraft 1.21.1, NeoForge и Java 21.
Для установки нужен лаунчер с поддержкой импорта `.mrpack`. Ниже приведён пример для [Prism Launcher](https://prismlauncher.org/).

### 1. Скачай сборку

Открой [последний релиз](https://github.com/holmzi/eldervale/releases/latest), раскрой **Assets** и скачай `Eldervale.mrpack`.

Архивы **Source code (zip)** и **Source code (tar.gz)** - исходники инструментов репозитория, для установки сборки они не нужны.

### 2. Импортируй архив

В Prism Launcher нажми **Добавить сборку / Add Instance**, выбери **Импорт / Import** и укажи скачанный `Eldervale.mrpack`. Подтверди импорт и дождись загрузки файлов.

В другом лаунчере используй аналогичную функцию импорта Modrinth-сборок. Самостоятельно распаковывать `.mrpack` в папку игры не нужно: часть файлов лаунчер скачивает по ссылкам из архива.

### 3. Запусти Eldervale

Если лаунчер попросит выбрать Java, укажи **Java 21**. Запусти созданную сборку и дождись появления главного меню.

Версия Eldervale отображается в левом нижнем углу меню.

## Обновление

Обычно переустанавливать сборку не требуется. Встроенный обновлятор проверяет релизы при запуске и затем раз в час.

1. Когда появится окно новой версии, прочитай изменения и нажми **Обновить**.
2. Дождись скачивания и подготовки файлов в игре.
3. Игра закроется, а отдельное окно **Eldervale Updater** установит обновление.
4. Дождись сообщения о завершении, закрой обновлятор и снова запусти сборку через свой лаунчер.

Если обновление найдено, для продолжения игры его нужно установить. При обнаружении новой версии во время игры клиент выйдет в главное меню и предложит обновиться.

Если проверить обновления не удалось, появится предупреждение - игру можно продолжить.

## Установка новой версии вручную

Если встроенное обновление не работает:

1. Полностью закрой игру и обновлятор.
2. Скачай последний `Eldervale.mrpack` из [Releases](https://github.com/holmzi/eldervale/releases/latest).
3. Импортируй его в лаунчер **как отдельную новую сборку**, следуя инструкции выше.
4. При необходимости перенеси свои одиночные миры из `saves/` и личные ресурспаки из `resourcepacks/` старой сборки в соответствующие папки новой. Перед переносом сохрани копию миров.
5. Запусти новую сборку. Старую удаляй только после проверки перенесённых данных.

Папки `mods/`, `config/`, `pack/`, `shaderpacks/` и `updater/` из старой установки переносить не нужно - новая сборка уже содержит актуальные файлы.

## Изменения сборки

Разрешено добавлять собственные ресурспаки в `resourcepacks/`.
Менять состав модов, конфиги и другие файлы сборки нельзя.
`pack/` - встроенный ресурспак Eldervale, его обслуживает обновлятор.
